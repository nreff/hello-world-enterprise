# HelloWorld Enterprise

### 👉 [View the live site: nreff.github.io/hello-world-enterprise](https://nreff.github.io/hello-world-enterprise/)

There's nothing to install or run. Just open the link above.

**This is a joke.** It's a parody landing page for a fictional company that sells an overengineered platform for printing "Hello, World." Every company, person, quote, certification and statistic on it is made up, and nothing is for sale.

The whole site is a single `index.html`, hosted on GitHub Pages. Pushing to `main` updates the live site automatically.

Hero image: Apollo 8 "Earthrise" (AS08-14-2383, NASA, public domain). Not affiliated with or endorsed by NASA.
